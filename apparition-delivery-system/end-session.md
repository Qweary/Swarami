End the current development session. Do the following:

1. Summarize what was accomplished this session
2. Update `docs/project-context/current-state.md` with progress made
3. Update `coordination/SESSION-HANDOFF.md` with session summary, in-progress work, blocking issues, next steps, and files modified
4. Update `coordination/AGENT-STATUS.md` if any agent tasks are pending
5. If there are uncommitted changes, list them and ask Queue if they want to commit
6. Log any new bugs discovered in `docs/project-context/active-bugs.md`

Present a concise session summary to Queue with recommended next steps for the following session.
